# Leia o app em 2 minutos

O AetherML prevê a qualidade do ar da Grande Vitória para as próximas 120 horas (5 dias). Tudo nesta página em linguagem direta.

---

## O número grande (IQAr)

É o **Índice de Qualidade do Ar**, de 0 a 300+, calculado pela regra oficial CONAMA 491/2018. Quanto menor, melhor. Ele vale para a **estação selecionada, na hora atual**.

- A cor resume tudo: verde = Boa, amarelo = Moderada, laranja = Ruim, vermelho = Muito Ruim, roxo = Péssima.
- Ao lado vai o **poluente crítico**: o vilão da hora (ex.: PM25 = fumaça fina, O3 = ozônio do sol forte).

## Os 5 cartões de dias

Cada cartão resume um dia: a **média** em destaque e o **pico** com o poluente que o causou. Use a média para planejar a semana e o pico para decidir o horário de sair.

## O gráfico

A curva de 120 horas. Toque nos botões (PM2.5, O₃...) para ver cada poluente. As faixas coloridas ao fundo são as faixas oficiais. Passe o dedo/mouse sobre a curva para ver hora a hora.

## O mapa

Cada pílula é uma estação, com o IQAr atual dentro. Toque para trocar de estação. O botão **"Estação mais próxima"** usa seu GPS; o seletor no topo faz o mesmo manualmente — a escolha fica salva.

## "De onde vem esse número?"

De modelos de machine learning treinados com dados reais de satélite e meteorologia (guia 09 tem os detalhes e a precisão medida: **91,9% de acerto na faixa**). Não é chute nem média simples.
